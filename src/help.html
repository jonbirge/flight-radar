3D Flight Radar

Overview

3D Flight Radar displays real-time aircraft positions on an interactive 3D globe using ADS-B data from the OpenSky Network. Aircraft within the current viewport are polled automatically and displayed with FAA-style data blocks.

Controls Panel

The controls panel is located at the bottom-left of the screen.

Toggles

  • TRAILS — Show/hide aircraft trail lines.
  • DATA BLOCKS — Show/hide callsign and flight data labels on aircraft.
  • AIRPORTS — Show/hide airport marker dots and IATA/ICAO labels.
  • AIRSPACE — Show/hide Class B, C, and D airspace boundaries.
  • 3D VOLUMES — When enabled, airspace boundaries are extruded to their floor and ceiling altitudes. When disabled, they are drawn flat on the ground.

Adjustments

  • POLL INTERVAL — How often aircraft positions are refreshed (10s–60s). This adjusts automatically based on zoom level.
  • TRAIL LENGTH — How long trail history is retained (1–10 minutes).

Buttons

  • HOME — Return to your saved view, or the default starting location.
  • SAVE VIEW — Save the current camera position as your home view.
  • CONUS — Zoom out to show the continental United States.
  • 2D / 3D — Switch between 2D map and 3D globe view.
  • ROTATE — Toggle automatic camera rotation around the current viewpoint (3D only).
  • SETTINGS — Open the settings window.

Aircraft Info Panel

Click on any aircraft to open the info panel in the top-right corner. It displays detailed information:

  • Callsign and ICAO24 hex address
  • Squawk transponder code
  • Origin country
  • Altitude (feet), Ground speed (knots), Heading (degrees)
  • Vertical speed (feet per minute)
  • Latitude / Longitude coordinates
  • Trail points count and last ADS-B contact time

When an aircraft is selected, its trail history is extended and a higher-resolution track is fetched from the OpenSky API.

HUD (Heads-Up Display)

The top bar shows:

  • Clock — Current UTC time.
  • TRKS — Number of aircraft currently tracked.
  • UPD — Time of the last data update.
  • LAT / LON — Camera center coordinates.

Settings

Open via Edit > Settings (Ctrl+,) or the SETTINGS button.

  • Font Size — Size of data block labels on the map.
  • Theme — Dark (phosphor green) or Light mode.
  • Dark Mode Color — Customize the phosphor color in dark mode.
  • Color by Altitude — Aircraft and trails are colored by altitude band.
  • Thick Trails by Altitude — Trail width varies with altitude.
  • OpenSky Credentials — Enter API client ID/secret for authenticated access (higher rate limits).

Data Source

Flight data is provided by the OpenSky Network, a community-based receiver network for air traffic surveillance. Data is sourced from ADS-B transponders.

Anonymous access is rate-limited to one request every 10 seconds. Register for free API credentials at opensky-network.org for higher limits.
